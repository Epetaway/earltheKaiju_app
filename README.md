# Kaiju Coach

A private Android app for teaching Brazilian Jiu-Jitsu. Part of the **Earl the Kaiju** ecosystem, built by Earl Hickson Jr. (BJJ black belt, instructor, graphic designer and front-end developer).

Kaiju Coach keeps everything I need on the mat in one place: today's class, lesson plans, the class timer, attendance and my roster. It works with no internet connection.

> Status: Sprint 01 in progress on the `sprint/01-foundation` branch. `main` stays stable.

## Repository layout

| Folder | What it holds |
|---|---|
| `android/` | The Android app (Kotlin, Jetpack Compose, Room). Open this folder in Android Studio. |
| `docs/` | Product brief, architecture, design system, screen specs, data model, sync plan, QA reviews, case-study log. |
| `contracts/` | Data contracts shared with the planned desktop companion (backup / sync format). |
| `assets/brand/` | The approved Earl the Kaiju brand sources the app uses, with provenance. |
| `desktop/` | Placeholder for the planned React + TypeScript desktop companion. |

The public website is a separate project and is not part of this repository.
