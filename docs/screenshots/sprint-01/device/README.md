# Sprint 01 device screenshots

Full-screen captures (status bar, navigation bar and keyboard included) from CI's **Device run**:
`DeviceFlowTest` driving the real app on an Android 15 (API 35) Pixel 7 emulator, with
Accessibility Test Framework checks on every interaction. Fictional data; the app's clock starts
at 6:20 PM on Wednesday, October 21, 2026 and then runs in real time (the status bar shows the
emulator's own clock). Saved here at half resolution.
